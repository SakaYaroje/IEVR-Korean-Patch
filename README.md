# 빅토리 로드 한글패처 · 다운로드 자료

다운로드형 한글패처가 필요할 때 자료를 받고, SHA-256 검증 후 공용 캐시에서 재사용하는 배포 저장소입니다.

## 패처 다운
[한글패처 v1.0 릴리스](https://github.com/SakaYaroje/IEVR-Korean-Patch/releases/tag/1.0.0)

1. 1.0 릴리즈를 다운 받고 압축을 해제 한다
2. 압축 해제 후 IEVRKoreanPatcherOnline-1.0.0-20260914_210800_74c3470d-Setup.exe 파일을 실행 한다
3. 패처 설치를 진행하고 완료 되면 패처를 실행한다.

아래 영상을 참고하여 패치를 진행한다.
https://youtu.be/x07EPUzOync?si=ENyrc328N_WY_E6d

프로그램 설치 파일은 별도로 제공합니다. 최초 자료 다운로드 후 같은 데이터는 다시 받지 않으며, 사용할 때 파일 무결성을 확인합니다. 검증되지 않거나 손상된 자료는 게임에 적용하지 않습니다.

## 용량과 백업

프로그램·다운로드 캐시·게임 복원용 백업·수동 설치 ZIP은 서로 다른 파일입니다. 다운로드형 프로그램으로 바꾸어도 복원용 백업이나 수동 ZIP이 자동 삭제되지는 않습니다. 원본 백업은 필요 여부를 확인하기 전까지 보존하세요.

## 출처

기존 한글패치 자료는 이나즈마 일레븐 갤러리 한글패치팀의 작업을 기반으로 합니다. 원문 크레딧은 패키지에 포함되어 있습니다. 이 저장소는 원 제작팀의 공식 배포본이나 승인·보증을 받은 제품으로 표시하지 않습니다. 원작 및 제3자 자료의 권리는 각 권리자에게 있으며, 이 저장소가 새 라이선스를 부여하지 않습니다. 수정·통합 재배포 허가 확인은 완료한 것으로 표시하지 않습니다.

릴리스에 첨부된 README_KO.md와 SHA256.txt를 함께 확인하세요. 게임 적용 전에는 게임을 종료하고 패처의 검사·백업 절차를 따르세요.
